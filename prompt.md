# MovieFlix - Redux Toolkit Sprint

## Objective
Build a MovieFlix application using React, Vite, Redux Toolkit, and the TMDB API.

## Features
- Display popular movies
- Search movies
- Add/Remove favorites
- Filter by minimum rating
- Dark/Light theme
- Redux Toolkit state management
- Responsive UI

## Technologies
- React.js
- Vite
- Redux Toolkit
- React Redux
- TMDB API
- CSS

## Outcome
Developed a responsive movie application with centralized state management using Redux Toolkit and real-time movie data from the TMDB API.
