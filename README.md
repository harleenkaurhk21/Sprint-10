# 🎬 MovieFlix - Redux Toolkit Movie App

MovieFlix is a React + Vite application that displays popular movies using the TMDB API. The project uses Redux Toolkit for global state management, allowing users to search movies, filter by category and rating, manage favorites, and switch between Light/Dark themes.

---

### Live Demo

**Vercel:**https://sprint-10-delta.vercel.app/

---
## 🚀 Features

- Display Popular Movies
- Search Movies
- Add/Remove Favorites
- Redux Toolkit Global State Management
- Sidebar Filters
- Minimum Rating Filter
- Dark/Light Theme
- Responsive Design
- TMDB API Integration

---

## 🛠️ Tech Stack

- React.js
- Vite
- Redux Toolkit
- React Redux
- TMDB API
- CSS3
